# 🤖 دليل تشغيل وتفعيل بوت التليجرام الخاص بـ LuxeMines

لقد قمنا بتطوير وبرمجة بوت تليجرام متكامل وفائق السرعة لمساعدتك في إدارة شؤون اللعبة، استقبال طلبات الشحن والسحب بالدينار الجزائري (DZD)، وتزويد اللاعبين برابط التحميل المباشر للعبة.

وفرنا لك البوت بإصدارين كاملين وجاهزين للتشغيل الفوري:
1. **نسخة Python (`bot.py`)**: باستخدام مكتبة `pyTelegramBotAPI`.
2. **نسخة Node.js (`index.js`)**: باستخدام مكتبة `node-telegram-bot-api`.

---

## 🛠️ الخطوة 1: إنشاء البوت والحصول على التوكن (Token)
1. افتح تطبيق تليجرام وابحث عن البوت الرسمي لتطوير البوتات: **`@BotFather`**.
2. أرسل له الأمر: `/newbot`.
3. اكتب اسماً للبوت الخاص بك (مثال: `LuxeMines Assistant`).
4. اختر معرّفاً فريداً للبوت ينتهي بكلمة `bot` (مثال: `luxemines_dz_bot`).
5. بمجرد الانتهاء، سيرسل لك `@BotFather` رسالة تحتوى على **الـ Token (التوكن)** وهو عبارة عن سلسلة من الرموز والأرقام، قم بنسخه.

---

## ✏️ الخطوة 2: تخصيص الملفات بمعلوماتك الشخصية
افتح ملف البوت الذي تفضل تشغيله وقم بتعديل القيم التالية:

### لنسخة بايثون (`bot.py`):
* السطر 6: استبدل `"YOUR_TELEGRAM_BOT_TOKEN_HERE"` بالتوكن الذي حصلت عليه من `@BotFather`.
* السطور 46، 62، 78: استبدل `"your_telegram_username"` بمعرّف حسابك الشخصي على تليجرام (بدون علامة @) لكي يتمكن اللاعبون من الضغط عليه ومراسلتك مباشرة لإجراء عمليات الشحن كاش أو بريدي موب.

### لنسخة نود (`index.js`):
* السطر 4: ضع التوكن الخاص بك مكان `"YOUR_TELEGRAM_BOT_TOKEN_HERE"`.
* السطور 8: ضع معرّف حسابك التليجرام الشخصي (مثال: `https://t.me/your_telegram_username`) ليكون هو المشرف المسؤول عن تلقي الرسائل والدعم.

---

## 🚀 الخطوة 3: تشغيل البوت

### الخيار أ: تشغيل البوت محلياً على جهاز الكمبيوتر الخاص بك

#### إذا اخترت نسخة بايثون (`bot.py`):
1. تأكد من تثبيت بايثون على جهازك، ثم افتح نافذة الأوامر ونفذ:
   ```bash
   pip install pyTelegramBotAPI
   ```
2. قم بتشغيل البوت:
   ```bash
   python bot.py
   ```

#### إذا اخترت نسخة نود (`index.js`):
1. تأكد من تثبيت Node.js على جهازك، ثم افتح نافذة الأوامر ونفذ:
   ```bash
   npm install
   ```
2. قم بتشغيل البوت:
   ```bash
   npm start
   ```

---

## ☁️ الخطوة 4: استضافة البوت مجاناً ليعمل 24 ساعة دون انقطاع

لتشغيل البوت طوال اليوم دون الحاجة لإبقاء جهازك قيد التشغيل، نقترح عليك هذه المنصات الحرة المجانية:

### 1️⃣ منصة Render (موصى بها جداً للـ Node أو Python)
1. قم بإنشاء حساب مجاني على [Render.com](https://render.com/).
2. اضغط على **New +** ثم اختر **Background Service** (خدمة خلفية).
3. اربط حسابك بـ GitHub ليرى مستودع مشروعك.
4. حدد أمر التشغيل:
   * لـ بايثون: `python telegram-bot/bot.py`.
   * لـ نود: `npm --prefix telegram-bot start`.
5. سيتم تشغيل البوت تلقائياً فوراً وبشكل دائم ومجاني!

### 2️⃣ منصة Replit أو PythonAnywhere
* يمكنك ببساطة رفع ملف `bot.py` وتشغيله داخل كونسول مجاني في [PythonAnywhere](https://www.pythonanywhere.com/) لتحصل على استقرار واستمرارية لا متناهية.
